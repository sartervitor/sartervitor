## 🚀 Projetos em destaque

### 🎙️ Tagarela — Avatar reativo para streamers

Aplicação que permite utilizar um **avatar animado que reage à voz**, alternando estados da boca e dos olhos. Criada para quem deseja uma presença visual em lives ou gravações sem depender de uma webcam.

O projeto possui **duas versões**:

- 🌐 **Web:** interface acessível pelo navegador, com uso do microfone para controlar as reações do avatar.
- 🖥️ **Desktop:** aplicativo para computador desenvolvido com **Rust + WebView**, combinando uma interface web com a experiência de um programa instalado.

**Destaques:** entrada de áudio pelo microfone, estados de expressão, personalização de avatar e interface interativa.

**Tecnologias:** JavaScript · Tecnologias web · Rust · WebView · Áudio em tempo real

🔗 **[Experimentar o Tagarela na web](https://tagarela.vitorgsarter.chatgpt.site/)**

### 📚 Script Slides — Geração automatizada de apostilas

Ferramenta em **Python** criada para converter apresentações de slides em **apostilas estruturadas e formatadas**, reduzindo etapas manuais na produção de material didático.

O fluxo envolve a leitura de apresentações PowerPoint, a conversão de slides em imagens e a montagem de documentos Word, com organização e formatação padronizadas.

**Destaques:** automação documental, processamento de apresentações, geração de arquivos `.docx` e integração com o Microsoft Office no Windows.

**Tecnologias:** Python · python-pptx · python-docx · Pillow · pywin32

### 🌵 Malassombro — ARPG 3D inspirado no folclore brasileiro

Jogo de ação e RPG **em desenvolvimento na Unity**, ambientado no sertão nordestino e inspirado em causos, lendas e assombrações brasileiras.

O projeto reúne exploração de cenários, combates, habilidades, personagens originais, criaturas regionais e progressão narrativa. Entre os sistemas trabalhados estão **missões, inventário, interface de jogo, inimigos e companheiros invocáveis**.

**Destaques:** desenvolvimento de gameplay, organização de sistemas em C#, construção de mundo e integração de recursos 3D.

**Tecnologias:** Unity · C# · Desenvolvimento de jogos · 3D

### ✂️ CodeLink Barber — Sistema de gestão para barbearias

Projeto de desenvolvimento web voltado à organização de processos de uma barbearia, com foco na criação de uma solução administrativa prática.
